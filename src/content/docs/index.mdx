## 这本教程为谁而写

你会 Python，准备申请 Infra 实习，却被 FSDP、NCCL、KV Cache 和 TensorRT 这些名词同时包围。这里先建立系统地图，再沿训练与部署链路逐个解释；不要求你已经训练过大模型，也不把缩写当作解释。

## 每节怎样读

正文以工程现场的问题开头，解释中英术语，用一句话收束，再讲机制、上下游影响和 LabBot 落地；读完先自己回答，再展开自测答案。每节末尾列一手参考资料。示例数字是教学假设，实测结果只来自你自己的运行记录。

## 两条贯穿链路

训练：数据 → 解码/采样 → 前向 → 反向 → 通信 → 更新 → 检查点。

部署：观测/请求 → 排队 → 预处理 → 编码器/模型 → 动作头/解码 → 后处理 → 返回/执行。

LabBot 是虚构的桌面机械臂教学案例。它把通用 LLM Infra 与具身系统串起来；小型实验用于验证工程机制，不宣称训练出可用机器人策略。
