## The engineering problem

A working PyTorch model fails export on an unsupported operation. A compiled engine later fails to load on another machine.

> Keep this question in mind: Why does successful ONNX export not establish deployment success?

**Export · ONNX · TensorRT engine · Optimization profile**

> **In one sentence: Deployment compilation targets specific execution conditions; shapes, precision, and compatibility all require validation.**

Saving parameters stores values; exporting records executable computation and input constraints; compiling chooses implementations for hardware, precision, and shapes. ONNX is an interchange representation, not a promise that arbitrary Python exports faithfully or runs faster.

TensorRT optimizes supported graphs and builds engines. Dynamic inputs generally need accepted shape ranges and optimization points. A wide profile does not guarantee speed at every shape, and out-of-range inputs may fail. Unsupported operations or data-dependent control flow may require rewriting, partitioned execution, or a Plugin, each with costs.

TRT-LLM provides language-model-specific execution and serving capabilities. It cannot be assumed to optimize an arbitrary VLA end to end. Vision encoders, language backbones, and action heads may use different backends; boundary transfers can erase gains.

Do not assume engines are portable across arbitrary GPUs, TensorRT versions, or CUDA environments. Record build environment, target architecture, shapes, precision, and model hash; follow official compatibility rules. Version-dependent commands are not universal recipes.

**Validation chain:** PyTorch baseline → exported execution → compiled execution → complete service. Compare identical inputs for numerical error and task quality at every boundary before timing. Random inputs exercise shapes; real samples exercise distributions.

**LabBot in practice:** First export a stable-shape encoder or action head. Verify channel ordering, normalization, and action order before entering the feedback loop.
