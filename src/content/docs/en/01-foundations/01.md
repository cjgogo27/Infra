## The engineering problem

The model can finally grasp a cup, but its action arrives half a second late when connected to a camera. Training on eight GPUs is only slightly faster. Something must connect model capability to reliable execution.

> Keep this question in mind: Why might a kernel become twice as fast while the robot barely improves?

**Infrastructure · End-to-end performance · Service-level objective (SLO)**

> **In one sentence: Infra makes models complete tasks correctly, reliably, and on time within a resource budget.**

Start with two paths. Training: storage → decoding and sampling → CPU memory → GPU forward pass → backward pass → gradient synchronization → parameter update → checkpoint. Inference: request → queue → preprocessing → GPU execution → postprocessing → response. A robot continues through actuation to the next observation.

Algorithms concern what a model learns; Infra also explains delays, crashes, recovery, and resource consumption. These concerns interact. Compressing inputs may accelerate execution while changing information available to the model. Larger batches may improve throughput but change optimization or waiting time.

Our running example, **LabBot**, is a fictional camera-equipped tabletop arm. Images, instructions, and joint states enter; a future action sequence comes out. It is not a real product, and its example numbers are not hardware measurements. Small programs demonstrate engineering mechanisms before transferring them to large models. An LLM handles language; a VLM adds vision; a VLA produces actions. Their architectures differ, but data, memory, scheduling, and communication remain relevant.

Specify three things before optimizing: input distribution, correctness threshold, and resource/performance targets. For example: reduce batch-one p95 latency on the same GPU without degrading a fixed validation set. p95 is the latency below which 95% of measured samples fall, not the mean.

**Upstream and downstream:** Algorithms and products set data and quality requirements; hardware and control systems impose deployment constraints. Deliver reproducible configurations, logs, and comparisons.

**LabBot in practice:** Record camera timestamps, policy start/end times, and command dispatch. If decoding is slow, a faster Attention kernel may not help.
