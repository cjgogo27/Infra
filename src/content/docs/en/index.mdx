You know Python and are preparing for an Infra internship, but FSDP, NCCL, KV cache, and TensorRT seem to arrive all at once. Build a system map first, then follow training and deployment one mechanism at a time. Prior large-model training experience is not required.

## How to read each section

Begin with an engineering problem, learn the terms and a plain-language explanation, then examine mechanisms, dependencies, and the LabBot example. Answer the self-check before expanding it. Primary references conclude each section. Teaching numbers are assumptions; measured claims require actual run records.

## Two connected pipelines

Training: data → decoding/sampling → forward → backward → communication → update → checkpoint.

Deployment: observation/request → queue → preprocessing → encoder/model → action head/decode → postprocessing → response/actuation.

LabBot is a fictional tabletop arm connecting general LLM infrastructure to embodied systems. Small experiments verify engineering mechanisms; they do not claim to train a usable robot policy.
