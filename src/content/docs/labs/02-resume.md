## 运行

~~~bash
python labs/checkpoint.py
~~~

脚本在 CPU 上训练一个小网络，保存模型、AdamW、调度器、更新步数与 Python/PyTorch 随机数，然后继续 3 步作为基线。它重新创建模型和优化器，加载本地文件、恢复随机数，再跑同样 3 步，断言 loss 和参数严格一致。

本实验通过新对象模拟恢复，未启动新进程；真实项目还应增加新进程恢复与数据加载状态测试。合成数据按随机数生成，没有 DataLoader 预取，因此不覆盖真实数据管线的精确续接问题。

输出中 losses_match 与 parameters_exactly_match 应为 true。随机数恢复必须放在新模型初始化之后，否则初始化会消耗刚恢复的随机数流。

## 破坏一次，再修复

在单独副本中去掉调度器恢复，观察学习率和参数如何变化；去掉随机数恢复，观察输入改变；只加载权重，观察优化器动量丢失。每次只破坏一个条件。

脚本只加载自身刚生成的本地 checkpoint；不要把任意来源的模型文件当作可信输入。示例是同一文件系统的临时文件替换，未模拟对象存储或分布式保存。
