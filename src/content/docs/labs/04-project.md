## 选择一个可控模型

从已有视觉编码器或小动作头开始，使用合法可用且适合本机的权重与数据。记录来源、revision、许可证和预处理。不要求首先下载巨型 VLA。

## 逐层验证

1. 建立 PyTorch FP32 或合适精度基线，固定输入、随机数与 eval 模式。
2. 保存代表性输入输出，检查尺寸、布局、颜色、数值范围。
3. 按已安装 PyTorch 与目标后端的官方教程导出，记录不支持的操作。
4. 对比绝对/相对误差与任务质量，门槛应来自任务而非随意填写。
5. 分开测导出/编译时间、冷启动与预热后运行。
6. 加入真实解码和预处理，重测端到端；如果收益消失，保留这个结论。
7. 有条件时比较量化，并检查校准样本是否覆盖部署分布。
